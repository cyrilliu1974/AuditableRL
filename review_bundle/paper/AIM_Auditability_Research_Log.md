### Findings that change the proposed hypotheses

1. **The proposed H1 lookup accuracy is tautological under the current action definition.** The code determines C/D directly from the first emitted symbol. A lookup built from AIM sequences and their derived C/D actions will therefore recover the action by construction, including on a held-out set. A 90% threshold or a binomial test against 50% cannot establish that a learned symbol meaning has been discovered. The report's same-record lookup and evaluation adds leakage, but fixing the split alone does not fix this construct-validity problem.

2. **The action map is hand-specified, while the emitted symbol is policy-selected.** These are distinct objects. The threshold-based decoding rule is exactly auditable from a recorded symbol; that does not show that the symbols have learned semantic meaning, that the complete policy is reconstructable from the symbol log, or that the symbol caused Agent B's response. Any paper claim must say which of these is being tested.

3. **A deterministic argmax pass is not a replay of the training decisions.** During training, each symbol is sampled from a categorical distribution. Argmax provides a well-defined post-training evaluation policy, but it does not reproduce the sampled training trajectory. The protocol must report these as separate evaluation modes.

4. **Agent B has an image and label shortcut available.** B's policy input includes Agent A's message, the MNIST label, and an encoder representation of the same image. Message/action association or B's raw action accuracy cannot isolate the message contribution. Conditional baselines and interventions must keep the image and label fixed.

5. **The proposed H2 label is partly defined by the action decoder.** Coloring `z_e` by the first AIM symbol's C/D half is a useful descriptive view, but it cannot establish a discovered semantic cluster. Agent A's output also depends directly on the label embedding, so label composition is a relevant control. Silhouette measured only on a 2-D UMAP embedding should not be the primary evidence.

6. **The proposed H3 test needs a defined causal estimand and supported replacements.** Replacing one message position while fixing B's image and label is directionally appropriate. However, even/odd MNIST classes are not established as the relevant source of counterfactual messages, and a 50% flip-rate null is not justified by the implementation. Measure change in B's action distribution (and optionally argmax action) under predeclared, supported message replacements; include no-message/shuffled or other justified controls, report replacement support, and estimate uncertainty over paired inputs. Analyze token positions separately because the first and later symbols may play different roles.

7. **Five runs and a CV cutoff do not by themselves establish stability.** Reinforcement-learning results can have substantial run-to-run uncertainty. Report each seed and interval estimates; treat five seeds as exploratory unless an explicit precision or power target supports the conclusion. A CV threshold of 0.15 is not a universal standard and can be unstable when a metric's mean is near zero.

8. **Several code examples in the attachment do not match the checked-in program.** In the current helper, `interpret_aim_as_action` expects a sequence and indexes its first element, while the proposed audit calls it with a scalar `.item()`. The proposed H1 evaluates the data used to build the lookup. The attachment imports `UMAP` from `sklearn.manifold`, but the scikit-learn manifold API does not list UMAP; the UMAP project documents its own `umap.UMAP` API. Its SciPy `binom_test` call was deprecated and removed in SciPy 1.12, and the AIM requirements file does not list SciPy, scikit-learn, or UMAP. These examples require correction and dependency decisions before implementation.

### Research framing and candidate claims

The broad statement “RL training results are fully auditable from discrete-symbol logs without inspecting weights” is not yet established. A defensible study should separate at least these claims:

- **Trace replayability:** Given a recorded input identifier, label, emitted symbol sequence, decoder version, and reward-rule version, can an independent evaluator reproduce the interpreted C/D actions and rewards? This tests a documented deterministic interface, not learned semantic understanding.
- **Policy behavior under a declared inference rule:** Can a saved checkpoint and fixed evaluation protocol reproduce the argmax or sampled policy outputs on a held-out, identified dataset? This requires retaining policy checkpoints and recording the inference mode and random-number state where sampling is used.
- **Message contribution:** With B's image and label held fixed, do controlled changes to A's message change B's action distribution? This is a causal influence question, not a lookup-table accuracy question.
- **Representation association:** Are learned AIM outputs statistically associated with input features or labels after relevant conditioning and controls? Association and visualization alone are not causal or human interpretability evidence.
- **Training stability:** How do the above results vary across independent training seeds, with uncertainty shown rather than reduced to a single pass/fail CV threshold?

These should remain separate results. Success on trace replayability must not be promoted into a claim that the network's internal reasoning is understood.

### Analysis decisions to carry forward

- Keep a symbolic decoder replay check, but label it a deterministic implementation invariant, not the H1 test of learned symbol semantics.
- Define the principal causal outcome as B's probability of selecting C under each fixed message intervention; also report discrete argmax flips as a secondary, threshold-sensitive outcome.
- For B, compare message-conditioned behavior with at least a no-message or shuffled-message reference while preserving the same image and label. Do not assume this reference is a causal null without stating the estimand it identifies.
- Record original message, replacement message, token position, input/label identifier, B output logits or probabilities, and whether the case is in the empirical message support. Aggregate paired per-input effects, not a raw unpaired flip count.
- Do not use H1/H3 p-values against 0.5 unless the randomization mechanism actually implies that null. Choose inference after the estimand and sampling unit are fixed; account for paired inputs, training seeds, and multiple primary outcomes.
- For representation analysis, predefine which representation and label are compared. Evaluate quantitative separation in the stated space and include label-conditioned or permutation controls; treat UMAP as a visualization only.
- Establish a true policy-training/evaluation split first. The current RL loop samples from MNIST's `train=False` split, so simply running a full-set post-training audit on that same data would not be out-of-sample evidence. Preserve a locked evaluation partition before any AIM policy training.
- The current command-line `--gamma_rl` parameter is not consumed by the inspected learning update. Exclude it from causal/ablation interpretation until code makes it active and an implementation check confirms the effect.
- Keep the proposed `>= 0.90`, `>= 0.40`, `>= 0.30`, `CV <= 0.15`, and five-seed rules provisional. They need theoretical, empirical, or precision-based justification before preregistration.
- Before building a new evaluator, settle whether the experiment is about model-level behavior, training-trajectory reconstruction, or both. The current checkpoint/return path cannot support the latter without a source change.

### Open questions requiring evidence before implementation

1. Decide whether the paper's central claim is bounded to post-training policy behavior and message influence, or whether it still aims to claim reconstruction of training trajectories. The current source cannot substantiate the latter from symbols alone.
2. Decide whether to add a separate evaluation module or extend the core file. Prefer an isolated evaluator if it can load returned/saved models without changing existing training artifacts; code inspection must confirm feasibility.
3. Select the action-probability estimand and supported message replacement design after inspecting empirical message frequencies from a fresh, fixed checkpoint. No such frequencies have been measured in this turn.
4. Select inference methods and sample/run counts after defining the experimental unit and desired interval precision. Avoid claiming that a universal seed count or CV threshold follows from the cited work.
5. Decide whether an auxiliary held-out classification/probe task is in scope. It would address input-feature association but would not by itself establish causality or human interpretability.

### New source-level diagnosis: original cooperative objective predicts C/C collapse

- Inspection of the actual `multi_agent_game` update found that both policy losses multiply each agent's log probability by the same `joint_reward = reward_A + reward_B`; the individual rewards are recorded, but are not the REINFORCE return used by either policy.
- Exhaustive evaluation of `payoff` over C/D action pairs gives joint rewards: for even labels, C/C=10, C/D=4, D/C=4, D/D=0; for odd labels, C/C=8, C/D=3, D/C=3, D/D=0. Therefore C/C is the unique joint-reward optimum for both parity groups. The label-dependent adjustment changes reward values but never changes the optimal joint action. This makes the seed-0 all-C policy consistent with the specified shared objective, not evidence of a learned even/odd symbol rule.
- The environment reward consumes only each agent's decoded first symbol. Later AIM positions have no direct path to task reward. Reflection losses may train them as prediction targets, but that does not make them reward-grounded reasons for the action.
- Consequence for the experiment: the current environment cannot establish that AIM symbols explain a nontrivial learned decision. H₂/H₃ as written are mismatched to its objective, and the reported low-entropy collapse is structurally expected. Next, verify this reward table with a small local diagnostic, then build a controlled communication task with a private sender variable, no receiver-side shortcut, and counterfactual symbol interventions. Treat that redesigned task as a separate benchmark; do not retrofit its results as validation of the original AIM experiment.

### Controlled-game experiment 1: pre-run protocol

- **Question:** Can a trained AIM message carry a private target to a receiver whose own label/image inputs are constant, and does a supported change in that message change the receiver's action distribution with receiver context held fixed?
- **Task:** Sender A sees one of ten private labels; target action is C for even labels and D for odd labels. Receiver B always receives label 0 and a blank image. B's reward is +1 for the target action, -1 otherwise. This removes the image/label shortcuts present in the original AIM game. Use the pretrained AIM VQ-VAE from the existing checkpoint, freeze it, and train the original `AgentA`/`AgentB` policy modules using on-policy REINFORCE.
- **Planned run:** seed 0, 10,000 episodes, K=32, D=64, two-token messages, batch size 128, learning rate 0.001, entropy coefficient 0.01; evaluate 128 sampled sender messages per each of the ten labels (1,280 total).
- **Primary evidence:** (1) receiver argmax accuracy and probability-weighted accuracy under sender samples; (2) message shuffle and no-message controls; (3) the difference in `P_B(C)` when intervening on complete sender messages sampled under even versus odd private targets while keeping B's observation constant, with paired design information and a 95% bootstrap interval; (4) per-token mutual information with a permutation null; (5) exact action/reward reconstruction from a hash-chained symbol-only training trace without loading weights, plus a tamper-detection probe.
- **Pilot advancement rule:** require receiver accuracy at least 0.90, shuffle/no-message controls near the balanced 0.50 baseline, and a correctly directed even-versus-odd intervention effect whose 95% interval excludes zero. This is a pilot gate only; a causal/interpretability conclusion additionally requires independent seeds and a clear support check. Do not infer from raw high-cardinality whole-sequence MI.
- This benchmark can test message-mediated decision evidence under a deliberately controlled task. Even a positive result will not retroactively validate the original MNIST reward design or establish unrestricted complete auditability.
